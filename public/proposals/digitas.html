01Executive Summary
A greeting worth sharing.

Crestify is pleased to submit this proposal for the design, development, and deployment of an AI-powered personalized greeting web experience. Users scan a QR code from product packaging or promotional material, land on a responsive campaign microsite, share a short memory or story, and receive a warm, personalized greeting rendered as a branded digital card that can be downloaded, printed, or shared.

Our approach prioritises four things: a fast, mobile-first experience (most QR scans happen on phones over mobile networks), high-quality AI output with strict content-safety guardrails, campaign-grade analytics for measuring funnel performance, and privacy compliance aligned with India's DPDP Act, 2023.

02Our Understanding
A campaign activation, not a website.

This is a consumer-facing campaign activation, so the success criteria differ from a standard web project: the experience must load near-instantly on mid-range Android devices, complete the full journey in under two minutes, handle unpredictable traffic spikes (packaging-driven QR scans are bursty), and produce emotionally resonant, family-friendly AI output every single time — with graceful fallbacks when it cannot.

The proposed journey — QR scan → microsite → consent → details → questions → memory → AI greeting → branded card → download / share / print — maps cleanly to a multi-step wizard with server-side AI generation and a dynamic card-rendering engine. All ten functional scope items in the RFP are covered, along with analytics instrumentation for every funnel event specified.

04AI Architecture
Warm output, every time.

We recommend Anthropic's Claude (Haiku 4.5 tier) as the primary generation model — the best balance of speed, cost, and, critically for this campaign, tone quality and safety for family-friendly consumer content. Anthropic models are notably strong at warm, natural writing and resistant to unsafe output.

The generation pipeline
01

Input handling

User inputs are validated and sanitised server-side. The AI is never called from the browser; the API key never leaves our backend.

02

Configurable prompts

An editable prompt template (no code changes) combines brand tone with user inputs. Prompt versions are logged so quality can be tuned mid-campaign.

03

Two-stage moderation

Input screening for unsafe submissions before generation, plus output validation against safety and brand-tone rules. Failures trigger the fallback.

04

Instant fallback

On failure, timeout (>8s), or a safety flag, a pre-written, personalised-by-name template is served instantly — the user always gets a card, never an error.

05

Observability

Every attempt — success, fallback, failure, latency — is logged for the analytics dashboard and cost tracking.

05Data Privacy & Consent
Compliant by design.
  • Explicit consent — an unticked-by-default checkbox with linked Terms & Privacy Policy before any PI is captured; consent timestamp and policy version stored against each record, aligned with the DPDP Act, 2023.
  • Encryption — all PI (name, mobile, email, relationship, memory text) encrypted in transit (TLS 1.3) and at rest (AES-256 via Supabase).
  • Data minimisation — mobile/email fields enabled only if the campaign requires them; memory text retained only as configured (default: campaign duration + 30 days), then purged.
  • No AI training on data — user inputs are processed via API with no training on submitted data, per Anthropic's commercial API terms.
  • One-click export — CSV/Excel export of captured leads with consent status, on request or via a simple admin endpoint.
  • Access control — role-restricted database access with audit logging on all data exports.
06Analytics & Tracking
Measured, funnel to outcome.

GA4 via Google Tag Manager, with a complete custom event taxonomy covering every interaction in the RFP.

GenerationGreeting generated (success), AI fallback served, AI failure, generation latency
OutcomeCard downloaded, shared (WhatsApp / native), printed

Per-SKU QR attribution: each packaging variant gets a unique UTM-tagged URL, so the brand sees which product lines drive the most scans. A weekly automated summary (scans, completions, conversion rate, drop-off) can be shared with the campaign team.
